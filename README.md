# dezservis.kz

Сайт https://dezservis.kz/ (ТОО «Казахстан Мед Дез»). Действующая версия — папка `site/`;
первая версия (копия с Тильды) сохранена в архиве `dezservis V1.0/`.

- `index.html` — главная страница (разметка Тильды, все тексты, ссылки, телефоны, цвета).
- `images/`, `css/`, `js/`, `favicon.ico` — фотографии и библиотеки Тильды, скачанные локально.
- `assets.txt` — список этих файлов и адресов, откуда они скачиваются.
- `scripts/fetch-assets.sh` — докачивает недостающие файлы (запускается GitHub Action
  «Fetch site assets» при изменении `assets.txt`, либо вручную).

Заявки с форм уходят в Битрикс24 (`kazakhstanmeddez.bitrix24.kz`, форма `inline/1/ghr8tc`) —
это работает без Тильды. Счётчики: Яндекс Метрика 103897465 и Google Tag Manager GTM-TPNSV8RB.

Сайт состоит только из статических файлов: его можно разместить на любом хостинге
(GitHub Pages, Netlify, обычный хостинг), загрузив содержимое репозитория в корень сайта.

## Дизайн

`css/hig.css` подключается последним и приводит страницу к принципам Apple Human Interface Guidelines:
системный шрифт (SF Pro на устройствах Apple, Inter из `fonts/` на остальных), контраст белого текста
на кнопках не ниже 3:1, области нажатия от 44 px, единые скругления, состояния фокуса и нажатия,
поддержка «Уменьшения движения» и безопасных зон iPhone. Там же точечные правки выравнивания блоков.

## Новая версия сайта (`site/`)

Сайт на PHP без базы данных: услуги, цены, отзывы, дезсредства, статьи и админ-панель `/admin`.

- Тексты, цены услуг, отзывы: `site/app/data.php`. Фото и видео команды (блок «Наша работа на объектах»): список `gallery` в том же файле, фото — `site/assets/img/<имя>.webp` и превью `<имя>-sm.webp`, видео — `site/assets/video/*.mp4` (H.264, до ~2 МБ). Цена `null` показывается как «по запросу», пустой список отзывов скрывает блок.
- Телефон, адрес, реквизиты, ссылки, счётчики: `site/app/config.php`.
- Прайс дезсредств (`/dezsredstva`): правится в админке, раздел «Дезсредства» (`/admin/catalog`): цены, названия, фасовки, «под заказ», новые товары и категории, загрузка всего прайса файлом CSV из Google-таблицы и откат последнего изменения. Правки хранятся на сервере в `storage/catalog.php` и не затираются при повторной заливке сайта. Исходный прайс в комплекте — `site/app/catalog.json` (`php scripts/import_catalog.php price.csv`). Фото товаров: в админке у каждого средства (поле «Фото») или все сразу из Excel-версии таблицы: `python3 scripts/catalog_photos.py part1.xlsx part2.xlsx` — фото каждой фасовки по артикулу в той же строке, в `site/assets/img/catalog/`; на сайте фото меняется при выборе фасовки. После `import_catalog.php` фото нужно привязать заново этим же скриптом.
- Статьи пишутся в админке и хранятся в `site/storage/` (в git не попадают). Картинки статей — в `site/uploads/`.
- Первый вход в `/admin`: ключ установки появляется в `storage/setup-key.php` на сервере.
- Для хостинга: содержимое `site/` загружается в `httpdocs`, PHP 7.4+, Apache с `.htaccess` (Plesk).
- Локально: `php -S 127.0.0.1:8000 -t site site/dev-router.php`.

### Скорость (Google PageSpeed)
- Счётчики (GTM, Яндекс Метрика), форма Битрикс24 и карта загружаются после первого действия посетителя (прокрутка, касание, клавиша) или через 5 секунд после загрузки страницы. События и цели до этого копятся в очереди и не теряются.
- `site.css` вставляется прямо в страницу (`site_css()` в `lib.php`), отдельного запроса нет.
- Крупные фото имеют уменьшенную копию `<имя>-sm.webp`: телефоны получают её через `srcset` (`img_srcset()`). При замене фото услуги, главного фото или сертификата обновите и копию `-sm`.
- Цвета кнопок и ссылок (`--tint`, `--wa` в `site.css`) подобраны с контрастом не ниже 4.5:1 к белому — не светлее.
