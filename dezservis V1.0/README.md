# dezservis V1.0 (архив)

Первая версия сайта dezservis.kz: копия страницы с Тильды с доработками дизайна
(`css/hig.css`) и счётчиком GTM. Сохранена для истории и на случай отката.
Действующая версия сайта — папка `site/` в корне репозитория.

`fetch-assets.sh` докачивал картинки и библиотеки по списку `assets.txt`
(пути внутри скрипта рассчитаны на старое расположение в корне репозитория).
